# Exercicios de logica em Python

Colecao de exercicios classicos de logica de programacao, cada um no seu
proprio arquivo: fizzbuzz, fibonacci, fatorial, numero primo, palindromo e
tabuada.

## O que pratiquei

- Loops e condicionais (`for`, `if/elif/else`)
- Funcoes com retorno de lista
- List comprehension
- Fatiamento de string (`[::-1]`) para checar palindromo
- f-strings para formatar saida

## Como rodar

Cada arquivo roda sozinho e mostra um exemplo:

```
python fizzbuzz.py
python fibonacci.py
python fatorial.py
python numero_primo.py
python palindromo.py
python tabuada.py
```

Ou roda tudo junto:

```
python main.py
```
